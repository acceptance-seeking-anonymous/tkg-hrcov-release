# registration/pilots/

Decision rules of the two TGB 2.0 pilots (tkgl-polecat, tkgl-smallpedia) and the tkgl-smallpedia direct-static-edge addendum, used
by `src/pilot_polecat/pc_agg.py`, `src/pilot_smallpedia/sp_agg.py` and `sp_agg_nd.py`. They are not part of the manuscript bundle
and not covered by `verify_registration_hashes.py`; host names and paths in them were redacted for this release (the files are
therefore not byte-identical to the originals).
